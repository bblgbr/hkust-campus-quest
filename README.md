# HKUST Campus Quest

A three-chapter browser game built around 46 panoramas and the Clear Water Bay campus map from the [HKUST Campus Virtual Tour](https://campus-vr.hkust.edu.hk/). Chapters 1 and 2 are playable. Chapter 3, **Exploring 3D world in HKUST**, is marked as in development.

## Play online

Play at <https://bblgbr.github.io/hkust-campus-quest/>. GitHub Pages deploys the `dist/` folder on each push to `main`.

## Run locally

On macOS, double-click `Start Campus Quest.command`. On other systems, run `python3 serve_local.py` from this folder, then open the printed local URL. No npm, account, or cloud service is required for local play.

The map and panorama imagery are from the official HKUST virtual tour and remain HKUST property. The puzzle and interface were created for this project.
